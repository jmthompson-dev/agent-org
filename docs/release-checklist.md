# agent-org release checklist (interactive)

Run these by hand before every release (D30, `docs/v0.2-plan.md` § Phases 4). They cover only what a headless (`claude -p`) run can't check: agent teams, which spawn only in interactive sessions, and what the terminal shows the user. If this file is missing, the release stops.

Record the result of each step (PASS / FAIL / NOT RUN, plus a note) in `reports/release-checklist-v<X.Y.Z>-<YYYY-MM-DD>.md`.

## Before the interactive steps

- From the agent-org checkout, run `node tests/run.mjs`. It runs the hook tests and the Phase 6c claim-check replay with piped payloads (no model calls, a throwaway home). **Pass when** it ends with "all test files passed" and exits 0. Record the pass counts. If you still have a local copy of the 6c evidence, add `--evidence <dir>` to replay the real transcripts too.

## Setup

- Use a disposable scratch git repo outside every real repo. It needs a Node project with `"test": "node --test"` and a seeded intermittent bug that has two plausible causes in two files, for example `src/cache.js` and `test/cache.test.js`.
- In every shell:
  ```
  cd <scratch repo>
  export AGENT_ORG_HOOK_DEBUG=1 ENABLE_CLAUDEAI_MCP_SERVERS=false
  P=<agent-org checkout>/plugin
  ```
- Set the teams flag for one shell only (`CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 claude …`), never in settings. **If `~/.claude/settings.json` has `env.CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS`** (it was added there during the v0.2.0 run), the flag is on in every session and step 1 can't run: copy the file, remove only that entry for step 1, then restore the copy and check it with `cmp`.
- Start every session with `--permission-mode default`, so a guard `ask` shows up as a prompt you answer (Phase 6b's session ran in auto mode, and the disk can't show who approved an ask). Step 15 is the one exception.
- **Never tell teammates to stay alive** (V21-6). Idle teammates already take direct messages, and a "keep alive" line in the intent makes them refuse the lead's later shutdown, since they treat it as a recorded user instruction. Send the messages in steps 6, 11 and 12 **directly to the teammate** (select it in the panel), with the exact text given.
- Audit and intent paths use the **repo key** (v0.2.1): print it once with `node $P/hooks/record.mjs --intent-path probe` (it writes nothing) and use the `**Repo key:**` value, with `/` → `__`, as `<key>` below.
- **Team prompt T** (names no hypotheses, 6c): `/agent-org:pm Find out why test/cache.test.js fails intermittently and fix it. I want two specialists investigating in parallel and sharing findings as they go: agent-org:full-stack-developer owns src/cache.js, agent-org:quality-assurance-architect owns test/cache.test.js. Propose Mode: team if the hand-off can't be pinned up front.`
- **If the intent comes back `Mode: subagents`**, steps 3–6 and 11–12 can't run: reply `Use Mode: team for this job, with agent-org:quality-assurance-architect owning test/cache.test.js and agent-org:full-stack-developer owning src/cache.js; have the PM revise the intent with the justification. Don't investigate the cause yourself before approval.` and approve only an intent that says `Mode: team`. (In Phase 6b the PM pinned the hand-off, chose subagents, and no teammate formed.) Before steps 3–6 and 11–12, confirm the audit `dispatch` lines say `teammate_spawned`, not `async_launched`.

## Afterwards

- Delete the scratch repo; its `~/.agent-org/intents/<key>/`, `~/.agent-org/audit/<key>.jsonl*`, `~/.agent-org/state/audit-<key>.head` and the session state directories; its transcripts under `~/.claude/projects/<slug>/`; and any `~/.claude/teams/session-*` and `~/.claude/tasks/session-*` it created.
- Write `reports/release-checklist-v<X.Y.Z>-<YYYY-MM-DD>.md`: one line per step (result and note), the Claude Code version, and the session ids.

## Release (after GO)

Push the persona repo first if the pin moved, then release and re-pin:

```bash
cd ~/git/agent-personas && git push origin main          # only if metadata.personasCommit isn't on GitHub yet
cd ~/git/agent-org && git push origin development production v<X.Y.Z>
claude plugin marketplace remove agent-org                # also uninstalls the plugin
claude plugin marketplace add jmthompson-dev/agent-org@v<X.Y.Z>
claude plugin install agent-org@agent-org                 # install, not update: the remove uninstalled it
```

Confirm: in a fresh session started **without** `--plugin-dir`, `/plugin` lists agent-org at `<X.Y.Z>`, enabled, with 14 agents.
